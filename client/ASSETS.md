# goldminer · 素材清单

黄金矿工的入库素材（`client/assets/`）与素材流水线。**总计 589.6 KB**
（改造前 3551.9 KB，压到 1/6）。音效占 210.7 KB，位图与文本占 378.9 KB。

## 一、素材流水线（`client/tools/bake_assets.py`）

原图不入库：产物即入库素材，原图只在 git 历史里。要重跑流水线时：

```powershell
git archive 2fda476 client/assets | tar -x -C build/art_raw
python client/tools/bake_assets.py --src build/art_raw --dst client/assets
```

`--ui-only` 只重生成程序化 UI 底板（不需要原图，随时可跑）。

流水线做四件事：

1. **统一成一套**：老版小图（`x.png`）与新版 AI 美术（`x2.png`）并存两套、
   运行时还留着「优先 x2、回退 x」的双份查找。流水线把新版美术统一落成
   `x.png` 一套，老版整批删除，运行时只认一个名字。
2. **压体积**：按**实际显示尺寸的 2 倍**缩放 + 调色板量化。屏幕上最多就
   那么多像素，留着 4 倍分辨率只是白占仓库（`mine.png` 488 KB → 108 KB，
   `claw_sheet.png` 未量化 162 KB → 34 KB）。
3. **烘朝向帧**（见下节）。
4. **生成 UI 底板**（程序化，见下节）。

## 二、朝向精灵表

引擎运行时转不了图——`Canvas.BlitImage` 只有源矩形 `(sx,sy,sw,sh)`，没有
旋转、没有水平翻转；`Gui.SpriteBatch` 的每精灵也只有
`dx,dy,dw,dh,sx,sy,sw,sh,tint`。所以方向只能**离线预烘焙**，运行时按
角度取帧。

### 爪子方向表 `claw_sheet.png`（2880×151，12 帧）

| 帧索引 | 对应摆角 | 说明 |
|---|---|---|
| 0 | 25° | 摆角区间下界（钩子在观者最右） |
| 6 | 90° | 垂直向下 = 原图姿态（钩心正下方） |
| 11 | 155° | 摆角区间上界（钩子在观者最左） |

- 步长 = (155 − 25) / 12 ≈ 10.8333°，帧 6 正好落在 90°。
- 帧内**铰点（绳头）位置固定**在 (120, 43)，**爪钳咬合线**在 (120, 129)：
  运行时把咬合点对到「绳长」末端，绳头与矿灯、钩尖三者落在同一个像素点
  上——绳子与钩子不错位。
- 源矩形 = `(帧号 × 240, 0, 240, 151)`，**帧宽是入库图像素**（240），不是
  显示像素（显示 109×69）。
- 取帧索引的纯函数在 `client/src/GoldminerFacing.zan`：

```zan
GoldminerFacing.ClawFrame(angleDeg)   // 摆角 → 帧号（0..11，越界夹紧）
GoldminerFacing.ClawSrcX(frame)        // 帧的源 X（源图像素）
```

### 矿工朝向表 `miner_sheet.png`（380×272，2 帧）

| 帧索引 | 含义 | 来源 |
|---|---|---|
| 0 | 朝左 | 原图（镐在观者左侧） |
| 1 | 朝右 | 原图水平镜像（镐跑到观者右侧） |

- 源矩形 = `(帧号 × 190, 0, 190, 272)`。
- 取帧索引的纯函数：

```zan
GoldminerFacing.MinerFrame(angleDeg)  // 摆角 → 帧号；死区返回 -1（保持上一帧）
GoldminerFacing.MinerSrcX(frame)
```

- **朝向规则**：摆角 < 90° 时钩子在观者**右**边（方向向量 `(cos a, sin a)`，
  x 分量为正），矿工朝右；> 90° 时钩子在观者左边，矿工朝左。90° 附近是
  **死区**（82°~98°），返回 −1 表示"保持上一帧"——每次摆过垂直线都翻一次
  脸太闹。
- **朝向可读性**：原图是正面视角，镜像本身看不出朝向，所以靠「镐在哪一侧」
  这个不对称标记——镐在朝向的那一侧，朝向一眼可辨（与 crawler 的提灯/
  独眼同一手法）。

## 三、美术底板（九宫格自切）

画布上的 HUD 面板与进度条走**美术底板 + 九宫格自切**（引擎没有
border-image，九宫格得自己裁源矩形拼 9 块，见
`client/src/GoldminerPaint.zan`）。底板由 `bake_assets.py` **程序化生成**
——大面积底板交给 AI 只会得到高频噪点，程序化可控，而且四张加起来不到
1 KB。

| 文件 | 尺寸 | 切角边长 | 用途 |
|---|---|---|---|
| `ui_hud_board.png` | 64×64 | 16 | HUD 顶栏底板（岩层横梁 + 金边 + 铆钉） |
| `ui_bomb_board.png` | 64×64 | 16 | 拆弹面板底板（黑铁板 + 红色警示边） |
| `ui_trough.png` | 48×16 | 4 | 进度条凹槽 |
| `ui_gauge.png` | 48×14 | 3 | 进度条填充（矿脉条） |

切角边长写在 `GoldminerPaint` 的常量里（`HudBoardBorder` 等），用例按它
钉住（切角边长必须小于底板一半，否则九宫格退化）。

## 四、皮肤包（`client/assets/skins/goldminer/skin.css`）

- 位置：构建时拷到 `build/goldminer/skins/goldminer/skin.css`（**与 exe
  同级**——`Gui.Styling.Skin.Roots` 查的是 exe 同级 `skins/` 与
  `assets/skins/`）。
- 一并拷公共包的两样东西：`skins/base.css`（控件基线，皮肤里的
  `var(--radius-*)` 等度量要靠它展开）与 `skins/dark/`（底座皮肤）。
- 运行时顺序：`UseSkin("dark")` → `UseSkin("goldminer")`，**反了会被默认
  皮肤盖回去**（见 `client/src/Scenes/MnRouter.zan`）。
- 皮肤包只能写纯色/渐变令牌：引擎的样式表**不解析 url() 背景图**，主题
  贴图一律走画布的美术底板 + 九宫格。
- 令牌值与 `client/src/GoldminerPalette.zan` 一一对应，用例按文件内容
  交叉核对（皮肤改了色板没改会被用例逮住）。
